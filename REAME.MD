# PhoneBook — тестовое задание (Qt)

Язык: C++17  
Фреймворк: Qt 6  

## Описание
Приложение «Телефонная книга» с возможностью:
- добавления и удаления записей
- сортировки по столбцам
- поиска по всем полям
- сброса к начальному состоянию (10 записей)

## Сборка под Linux
```bash
qmake
make
./PhoneBook
